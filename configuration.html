Configurer Organizer avec YouTube

Organizer ne peut pas accéder à ta bibliothèque YouTube sans ton autorisation. La connexion Google ne fonctionne pas en ouvrant index.html depuis un ZIP ou un chemin file://. Il faut publier ce dossier sur un hébergement HTTPS.

  1. Publie les deux fichiers index.html et configuration.html sur un hébergement statique HTTPS autorisant l'usage commercial, puis copie l'origine de l'adresse, par exemple https://mon-site.example (sans chemin final).
  2. Dans Google Cloud Console, crée un projet Organizer, puis active YouTube Data API v3 dans « API et services ».
  3. Configure l'écran de consentement OAuth (nom Organizer, e-mail de support, utilisateurs test). Ajoute ton compte Google comme utilisateur test si l'application est en mode test. Demande le champ d'application youtube.readonly et complète les informations de confidentialité exigées par Google.
  4. Dans « Identifiants », crée un ID client OAuth 2.0 → Application Web. Dans « Origines JavaScript autorisées », ajoute exactement l'origine HTTPS du site. Ne mets jamais un secret client dans ce fichier.
  5. Sur le site hébergé, colle l'identifiant client (qui se termine par .apps.googleusercontent.com), clique sur « Connecter YouTube » et autorise l'accès en lecture seule.
  6. Organizer récupère les playlists associées à ton compte via l'API et leurs vidéos. Pour les playlists d'autres créateurs enregistrées dans ta bibliothèque mais non exposées par l'API, colle leur lien dans « Ajouter une playlist » : Organizer mémorise ce lien localement.

La mise en production publique peut exiger une vérification OAuth par Google. Les vidéos privées, supprimées ou inaccessibles ne seront pas récupérées. Les filtres de style et de version reposent sur les titres et descriptions disponibles : ils ne constituent pas une classification musicale garantie.

Cette version est un site web connecté à YouTube, pas un APK Android. Les fonctions Android natives (liste des applications, widgets, biométrie) et les abonnements Premium ne sont pas intégrés ici.
